# Казкова подорож

Інтерактивний 3D-кубик для авторської психологічної гри. Український інтерфейс, шість CSS 3D-граней, рівноймовірний вибір через Web Crypto, кидок 2,6 секунди, золоті іскри й синтезований звук із вимикачем. Підтримуються клавіатура, оголошення результату та зменшення анімації відповідно до налаштувань пристрою.

## Попередній перегляд

Потрібен Node.js 22 або новіший. У каталозі репозиторію виконайте:

```sh
npm ci
npm run dev
```

Відкрийте адресу, яку покаже Vite (типово порт 5173), у браузері або через панель портів вашого редактора. Звук активується після натискання кнопки кидка. Вимикач звуку розташований угорі праворуч.

```sh
npm test
npm run build
npm run preview
```

Остання команда запускає попередній перегляд готової збірки на порту 4173. Файли для публікації зберігаються в `dist/`. Відносні шляхи дозволяють розміщення в підкаталозі GitHub Pages.

## GitHub Pages

1. Додайте створені файли до коміту та надішліть його у гілку `main` на GitHub.
2. У репозиторії відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow **«Опублікувати сайт»** автоматично збудує та опублікує сайт після push у `main`. Його також можна запустити вручну через **Actions → Опублікувати сайт → Run workflow**.
4. Після успішного виконання адресу сайту буде показано в Pages та в результаті deployment.

Публікацію ще не виконано. Сервер, база даних, токени та платні сервіси для сайту не потрібні.

## Дизайн і перевірки

Оновлений дизайн використовує оригінальний золотий логотип, вирізані з `kazkova-dice-design.png..png` шість граней кубика, кнопку та рамку результату. Файли містяться в `assets/original/`. Оригінальну карту витягнуто з `ppt/media/image1.jpg` наявної презентації; її можна розгорнути під основною сценою як ілюстрацію, без додаткових механік.

`scene-restored.png` — фон, відредагований за оригінальним макетом за допомогою генеративного відновлення: прибрані статичний кубик, написи та кнопки, реконструйовані закриті ділянки. Це не оригінальний окремий шар фону. Решта растрових елементів вирізана з макета або взята з оригінальних файлів. Спрощений SVG-пейзаж більше не використовується.

Кубик лишається CSS 3D-об'єктом із шістьма текстурованими гранями. Камера має сталий нахил; анімація кидка, рівноймовірний вибір, український результат і синтезований звук збережені.

Перевірено: 5 тестів `npm test`, production-збірка, кидок і відповідність результату в Chromium, вимикач звуку, завантаження ресурсів без помилок, мобільна ширина 390 px без горизонтального прокручування та відкривання карти. Оновлення підготовлено до публікації через наявний workflow GitHub Pages після об’єднання в main.
