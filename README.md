# Казкова подорож

Інтерактивний 3D-кубик для авторської психологічної гри. Український інтерфейс, шість CSS 3D-граней, рівноймовірний вибір через Web Crypto, кидок 2,6 секунди, золоті іскри й синтезований звук із вимикачем. Підтримуються клавіатура, оголошення результату та зменшення анімації відповідно до налаштувань пристрою.

## Попередній перегляд

Потрібен Node.js 22 або новіший. У каталозі репозиторію виконайте:

```sh
npm ci
npm run dev
```

Відкрийте адресу, яку покаже Vite (типово порт 5173), у браузері або через панель портів вашого редактора. Звук активується після натискання кнопки кидка. Вимикач звуку розташований угорі праворуч.

```sh
npm test
npm run build
npm run preview
```

Остання команда запускає попередній перегляд готової збірки на порту 4173. Файли для публікації зберігаються в `dist/`. Відносні шляхи дозволяють розміщення в підкаталозі GitHub Pages.

## GitHub Pages

1. Додайте створені файли до коміту та надішліть його у гілку `main` на GitHub.
2. У репозиторії відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow **«Опублікувати сайт»** автоматично збудує та опублікує сайт після push у `main`. Його також можна запустити вручну через **Actions → Опублікувати сайт → Run workflow**.
4. Після успішного виконання адресу сайту буде показано в Pages та в результаті deployment.

Публікацію ще не виконано. Сервер, база даних, токени та платні сервіси для сайту не потрібні.

## Дизайн і перевірки

Зоряна палітра, золоті рамки, клубок, пейзаж із замками й кубик створені за мотивами наданого макета. Оригінального логотипа чи окремого зображення пейзажу в репозиторії не було: використані власні SVG та CSS, без зовнішніх шрифтів і зображень. Пейзаж є стилізованою векторною ілюстрацією, а не точною копією живописного фону макета.

`npm test` перевіряє всі шість результатів, геометричну відповідність передньої грані, відкидання випадкових значень, які спричиняють зміщення ймовірності, блокування кнопки та вимикач звуку. Браузерна візуальна перевірка в поточній хмарній сесії не виконана: завантаження Chromium блокується мережевою політикою (HTTP 403).
